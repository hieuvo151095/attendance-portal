# Prompt to paste into the new agent

You are rebuilding an existing single-file web page EXACTLY as it is. Do not redesign, refactor, translate, rename or "improve" anything.

## What you are given
A folder `eco_school_ecosystem_source/` (or its zip) containing:
- `dist/index.html`  the finished page (self-contained: HTML + CSS + JS inline, no external requests). THIS IS THE SOURCE OF TRUTH.
- `src/`  the same page split into parts: `shell.html` (markup with `{{CSS}}` and `{{SCRIPT}}` placeholders), `css.css`, `saved_data.js` (legacy model), `working_data.js` (current model, includes the first roadmap), `rebuild_data.js` (data of the second board, generated by `tools/gen_rebuild_data.py` from `tools/modules_full.json`), `engine.js` (rendering, filters, both roadmap boards, persistence), `return_statement.js`.
- `build.py`  rebuilds `dist/index.html` from `src/` (Python 3, no dependencies).
- `SHA256SUMS`  fingerprints. The correct page has SHA-256 `39c2023baeccf776a97a0a2208d8dcdaa56b892877bf97ae1850d92052299094` (657,965 bytes, UTF-8).
- `tests/verify.js`  smoke test (jsdom + css-tree). `README.md`  architecture notes.

## What to do (in this order)
1. Copy `dist/index.html` byte for byte to the target. If the target accepts a single HTML file, you are done after step 4.
2. Optional check that the sources are complete: run `python3 build.py`, then `sha256sum dist/index.html`. It must equal the hash above. If it does not, stop and report the difference; do not patch around it.
3. Run the tests: `cd tests && npm install && node verify.js ../dist/index.html`. Then `node verify_rebuild.js ../dist/index.html`. Expected last lines: `ALL CHECKS PASSED` (31 checks) and `ALL REBUILD CHECKS PASSED` (72 checks).
4. Publish / host the page unchanged.
   - If you are publishing on claude.ai as an Artifact: first call the Artifact tool with action `capabilities`, then publish `dist/index.html` with capabilities `{"db":{},"user":{}}` (the two roadmap boards save card positions to the shared database docs `roadmap/layout` and `roadmap/layout-rebuild`, falling back to browser localStorage keys `eco-roadmap-layout-v1` and `eco-roadmap-rebuild-layout-v1` when the runtime is absent). Do not hard-code seed data into the database.
   - On any other host: serve it as a static file. No build step, no server, no network calls are needed; the page works without the database capability (positions then save in the browser only).

## Rules
- No external scripts, fonts, images or network requests (the host blocks them).
- Keep all text exactly as is, including Vietnamese text, product names and abbreviations (ECC, NPP, QLTH, QLNT, MN, K12).
- Keep the Saved tab's content unchanged: it is a deep-frozen legacy copy on purpose.
- Keep every CSS rule at top level. A previous bug left an `@media` block unclosed and silently disabled about 140 rules; the test checks for this.
- Do not "fix" things that look odd (for example the product lines ECO Me and ECO Teacher appear under both the Mầm non and K12 branches on purpose; they are one shared object).
- The file contains internal company names and plans. Keep it private; do not post it publicly.
